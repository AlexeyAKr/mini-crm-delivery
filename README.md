# Mini-CRM доставки ChinaGoods

Веб-приложение для учёта заказов из Китая. Собирает заявки из Авито, Telegram и ручного ввода в одном месте: единый список, статусы, поиск по телефону, фильтры, сводка дня и ИИ-разбор сообщений клиента.

## Проблема

Заявки приходят из разных каналов, теряются. Менеджер не может за 5 секунд ответить клиенту, где посылка. Нет сводки: сколько заказов за день, на какую сумму, сколько доставлено.

## Что решает

- **Единый список заказов** со статусами и фильтрами по дню, статусу и каналу.
- **Поиск по телефону** в любом формате (`+7`, `8`, с пробелами, скобками, дефисами).
- **Статусная модель** с защитой от перескоков и откатов: `новый → подтверждён → в пути → доставлен` (плюс `отменён` из любого статуса, кроме финального).
- **Смена статуса** с обязательной причиной при отмене и историей изменений.
- **Сводка дня**: количество заказов, сумма, доставлено, отменено (без отменённых в выручке).
- **ИИ-разбор заявки** через GigaChat: менеджер вставляет текст клиента — форма предзаполняется.
- **Автоподстановка предоплаты** 50% от суммы заказа с возможностью ручной правки.
- **Защита от дублей** при повторных кликах «Сохранить».

## Запуск локально

```powershell
git clone <ссылка-на-репозиторий>
cd mini-crm-delivery
python -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
copy .env.example .env
# открой .env и вставь свой GIGACHAT_CREDENTIALS
streamlit run app.py

## Переменные окружения (.env)

    GIGACHAT_CREDENTIALS=<ключ GigaChat>
    GIGACHAT_SCOPE=GIGACHAT_API_PERS
    APP_TIMEZONE=Europe/Moscow
    DB_PATH=data/crm.sqlite

Ключ GigaChat получается в личном кабинете developers.sber.ru.

## Тесты

    pytest tests/ -v

Ожидаемый результат: 64 passed.

## Ограничения MVP

- Многопользовательский режим и роли — во вторую версию.
- Курьер-режим — во вторую версию.
- Интеграция с ВК-ботом ChinaGoods (заявки читаются вручную).
- Расчёт стоимости в юанях с учётом веса.
- Дашборд за 30 дней и графики.

## Что дальше (вторая версия)

- Курьер-режим: отдельный список на день, экспорт в Telegram.
- Чтение заявок из ВК-бота автоматически.
- Расчёт: юань × курс + вес × тариф.
- Уведомления клиенту при смене статуса.
- Дополнительные подстатусы: выкуплен, на складе РФ.
